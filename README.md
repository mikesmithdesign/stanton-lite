# Stanton's Lite — free one-page template for barbershops

A single-file HTML template with dark, warm, photography-forward styling,
smooth scrolling (Lenis) and scroll-triggered animation. No build step, no
frameworks — open `index.html` and edit.

**Live demo:** https://stanton-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html` — shop name, prices, review, hours.
2. Replace the photos in `img/` with your own (keep the filenames, or update the `src` paths).
3. Set your opening hours in the `HOURS` table near the bottom of the file
   (day 0 = Sunday; `[9,18]` = 9am-6pm; `null` = closed).
4. Upload anywhere — it's static files. Vercel, Netlify and GitHub Pages host it free.
